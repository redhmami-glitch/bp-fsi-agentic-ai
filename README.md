# Agentic AI · Financial Services — offres BearingPoint

Mini-site statique (HTML/CSS/JS, sans build) présentant 3 offres :
stage de fin d'études, Consultant (junior), Senior Consultant.

- Site : https://redhmami-glitch.github.io/bp-fsi-agentic-ai/
- Écran QR pour le forum : https://redhmami-glitch.github.io/bp-fsi-agentic-ai/qr.html
- QR à imprimer : `assets/qr.png` / `assets/qr.svg` (pointe vers `?src=forum`)

## Candidatures
Le bouton « Postuler » ouvre la messagerie du candidat avec un email pré-rempli
(poste, école, disponibilité, motivation, source). Le candidat joint son CV et envoie.
Adresse de réception : constante `RECRUITER_EMAIL` dans `assets/app.js`.

## Mettre à jour
Modifier les fichiers, puis `git commit` et `git push` : GitHub Pages republie en ~1 min.
